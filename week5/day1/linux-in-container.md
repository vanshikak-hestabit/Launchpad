# The container runs a minimal Linux environment.

## THE COMMANDS I USED:-

# 1. Entering the Container
-> docker exec -it <container-id> /bin/sh

# 2. Directory Structure
-> ls

# 3. Checking Processes 
-> ps

# 4. CPU & Memory Usage
-> top

# 5. Disk Usage
-> df -h

# 6. Logs
-> docker logs <container-id>
